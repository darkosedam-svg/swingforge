# WU-3A — CLI + backfill (`swingforge/cli.py`, branch `wu/3a`)

Built: five commands (`backfill`, `tournament`, `paper`, `web`, `report`) plus `swingforge/adapters/settings_reader.py` (`TransientSettingsReader`); 65 tests in `tests/unit/test_cli.py` (96% branch coverage on `cli.py`) + 3 in `tests/unit/test_settings_reader.py`. Gates green: `pytest -q -m "not slow"` (808 passed), full suite incl. `slow` (827 passed), `ruff check`/`format`, `mypy swingforge`, `lint-imports`. Code-review pass applied (C1/C2, I1-I7, a `--instruments` mismatch, and several minors); see below.

Commands: `backfill --venue {hyperliquid,oanda} --years N [--instruments SYM,SYM]`; `tournament --venue V [--out reports] [--seed 0] [--resume] [--run-id ID] [--entries/--exits/--sessions/--instruments ...] [--start/--end ISO8601]`; `paper --venue V --config entry|exit|session|venue:symbol [--poll-delay 5] [--abandon-open-trade]` (refuses `--config baseline|...`, the control); `web [--host 127.0.0.1] [--port 8787]`; `report --venue V [--run-id latest]` — the runbook should call `tournament` with an explicit `--run-id`, then `report --run-id` that same id (the fixed clock-minute id is gone). All take `--data-dir` (env `SWINGFORGE_DATA_DIR`); store path `<data_dir>/<venue>.duckdb`. `.env` loads via `load_dotenv()` with `override=False`: a real environment variable always wins over `.env`.

Bar clock (C1): `equity` (one row per live bar, written nowhere else) is a paper run's persistent bar counter. `_build_paper_runtime` forces `engine.ctx.bar_index = _WARMUP_4H_BARS - 1 + len(store.equity(run_id))` right after warm-up, so `Engine`'s `trade_id` (`f"{venue}:{symbol}:{bar_index}"`) never repeats across a restart.

Open-trade policy (C2): startup refuses (exit 3, naming the trade id + entry ts) if `trades` holds a row with `closed_bar IS NULL` for this run id — paper never restores a position across a restart. `--abandon-open-trade` upserts it closed (`closed_bar=opened_bar`, `realized_r=0.0`, `regime` unchanged) and echoes `abandoned open trade <id> at 0R`.

`_persist_bar` retries `duckdb.IOException` (the nightly incremental backfill holds the file for a few minutes): `PERSIST_RETRIES=30` × `PERSIST_BACKOFF_S=10.0`s (~5 min), `sleep` injectable; raises after. `tournament --resume` now requires `--run-id` (exit 2 otherwise) — no more racing the clock-minute. `tournament` prints `run id: …` and `passing configs:` (one id per line, `IS_SELECTED` passers included); `paper` prints `run id: …` at startup. `_drain_fill_log`'s cursor is the last-drained `FillLog` object, not an index, so it survives `broker.log`'s `maxlen` eviction. The `finally` flush in `_paper` never masks an in-flight exception from the stream (echoes its own failure instead). `web` refuses any host outside `{127.0.0.1, localhost, ::1}` without `SWINGFORGE_TOKEN`. `_paper` is now `_build_paper_runtime` (all startup wiring) + a short streaming loop.

Not built: no live orders; no retry on a venue error. Small decisions unchanged from before: `PerInstrumentCostModel` keys on `venue:symbol` (raises `LookupError`, not `KeyError`); Hyperliquid `--instruments` override outside `DEFAULT_PERPS` gets a 0.01 tick; paper's `baseline` entry seed is fixed (moot now that `baseline` is refused for paper).
