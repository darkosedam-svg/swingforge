# WU-2B — venue adapters: Hyperliquid + OANDA (branch `wu/2b`), code-review fixes applied

C1+C2 (paging): `HyperliquidBars.history` now sizes each page to `min(page_ms, 5000 * span_ms(tf))` instead of leaving it at the 4H-tuned default, and resumes a capped page from its own last candle's `t + one span` rather than jumping to the window end — the prior code silently dropped most of a long 1H history once the venue's real 5000-candle cap applied (reviewer's `repro.py`: 0 dropped now, was ~86%). A capped page whose last candle sits more than one span short of its window, followed by a completely empty resumed request, now raises `RuntimeError` instead of truncating silently. Pinned with a 4-year 1H history (~35,064 bars, exactly 8 calls) and a 1000-day Daily case; `FakeInfo` now caps at 5000/call like the real venue.

I2: the FX Sunday-session behavior (3 bars, below `MIN_HOURS_FOR_DAILY_RECUT`, dropped; Monday opens at 00:00 UTC) is now documented and pinned. `recut_daily` also rejects mixed-instrument input.
