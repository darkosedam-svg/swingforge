# WU-3B — integration tests (branch `wu/3b`)

Built `tests/integration/{__init__,conftest,synth}.py` plus `test_{determinism,no_lookahead,reconciliation,planted_edge}.py`: 20 tests (12 fast, 8 `slow`). Gates green — `pytest -m "not slow"` 706 passed in 60 s, `pytest -m slow tests/integration` 8 in 55 s, `ruff check`/`format`, `mypy swingforge`, `lint-imports`.

**`synth.py`.** `random_walk_store` wraps `build_store`. `planted_store(instrument, *, years, seed, edge)` scripts a real ICT setup every `_SETUP_SPACING` = 22 bars against the Daily fractal levels it maintains as it goes: approach → sweep (wicks 80 bp past the level) → order block → displacement leg → break of structure → retrace. Post-review: the retrace used to close **exactly** on the order-block midpoint (entry) every time, which meant every planted limit filled and `expires_in_bars` was never exercised — optimistic vs a live edge. `_UNFILLED_SHARE = 0.2` (drawn once per candidate slot, shared by `edge=True`/`False`) now stops that share of retraces `_UNFILLED_GAP`=1bp short of the entry for the whole 3-bar fill window instead; ICT still signals identically (self-test's ≥80% hit rate is unaffected — it counts signals, not fills). The self-test also now cross-checks a setup's swept level against `strategies/levels.py`'s `swing_lows`/`swing_highs` directly, not just `_Levels`' own bookkeeping.

**Planted run** (seed 0, 4 years, entries ict+baseline, exits `fixed_r_2`/`fixed_r_3`/`trail_1_2`, `NullCostModel`, `n_trials=8`). With the ~20% unfilled share: `edge=True` `ict|fixed_r_2` still **passes all six rules** — n_oos 209 (was 265), exp_oos 1.011R, DSR 0.9991, MAR 36.4 vs buy-and-hold 0.051; no `baseline` row passes. `edge=False`: every row still fails (n_oos ≥ 138, rule 1 holds, rule 2 = 0 everywhere).

**⚠ The CLI must mirror `synth.real_entry_factory` / `real_session_factory`**: `ict` → `ICT()`, `zones` → `Zones()`, `baseline` → `Baseline(target_trades_per_1000_bars=baseline_rate or 1.0, seed=seed)` (its randomness from that `seed` argument and nothing else), session → `SessionFilter(mode, instrument.session_profile)`.

Decisions: `test_no_lookahead` mutates a 2-year *planted* store (now checks open/high/low too, not just close) — `Zones` takes 7 trades in 4 years of an unplanted walk, which makes a mutation test vacuous there. `test_determinism`'s row-multiset check now uses `EXCEPT ALL` both directions (plain `EXCEPT` would call a duplicated row identical to a singleton one). **Built**: `test_nothing_passes_on_a_pure_random_walk` (spec §8) runs ict+zones+baseline over a fresh 4-year random walk (`WALK` instrument, seed 11, `n_trials=11`); no pooled row passes. `ict`/`baseline` never clear rule 1's n≥60 floor (max n_oos 23 — too few trades on an unplanted walk over four years to reach it) but re-evaluating rule 2 (DSR) on those same pooled OOS trades with the floor lifted still rejects every one, so the failure is statistical, not just a thin sample; no need to fall back to `_UNFILLED_SHARE=0.1`. Known gaps: `test_reconciliation`'s fill comparison is a broker-replay match, weaker than `test_engine_run_and_engine_step_close_the_same_trades`'s full engine-level equivalence; gate rule 5 is nearly free on this data since buy-and-hold's MAR is ~0.04–0.05.
