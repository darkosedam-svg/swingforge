# WU-3C — Dashboard

Built: `web/app.py` (`create_app(data_dir=None, token=None)`, module `app = create_app()`), `web/queries.py` (SQL/row helpers over a `Store`), `web/static/index.html` (vanilla JS, four tabs; a dependency-free inline-SVG chart, not Recharts, so there is no CDN to fail). 45 tests in `test_web.py` (643 total), 100% coverage on both `app.py`/`queries.py` (target 85%). Gates green: `pytest`, `ruff check`/`format`, `mypy swingforge`, `lint-imports`.

⚠ **CLI must follow these conventions** (no lab/tournament/CLI code exists yet, so this WU only had `Store`'s schema to build against): paper run ids `paper:{venue}:{config_id}`; a tournament's `results` rows are keyed by the parent `run_id`, its children's `trades`/`equity` rows by `f"{run_id}:{config_id}"`; an open paper position is a `trades` row with `closed_bar IS NULL`. "Latest tournament" = pooled across every present venue store, picking the `run_id` owning the single greatest `ts` among non-`paper:` `results` rows (`SELECT run_id, MAX(ts) ... GROUP BY run_id`), then gathering that `run_id`'s rows from *every* store (a tournament can span venues). `gate`/`cost_stress` are capped to every passing config + top 50 by `exp_oos` + every `IS_SELECTED` row (deduped, plus a sibling `*_omitted` count) — no longer the full row set. Trade-detail's bars window is `[entry_ts − 30·4h, exit_ts + 10·4h]` (`exit_ts` = last leg's fill ts, else `entry_ts`).

⚠ **Concurrency (paper runner, read this)**: DuckDB's file lock is *exclusive* across processes even for a read-only open — any overlap fails outright, regardless of duration. Your side of the bargain: open your venue's store only briefly, at each 4H bar close, and close it again immediately. The dashboard's side: every open (each GET, and the settings PUT) retries a `duckdb.IOException` up to `OPEN_RETRIES` times, `OPEN_BACKOFF_S` apart, then returns `503 {"detail": "venue busy"}` — never a raw 500.

Auth: `GET /` (the static shell) is always open; `/api/*` requires `Authorization: Bearer <token>` (constant-time check) when `token`/`SWINGFORGE_TOKEN` is set, else 401; with a token set, `/docs`/`/redoc`/`/openapi.json` are disabled (404) so they can't leak the API shape. No token means fully open — bind to `127.0.0.1` only. `data_dir` defaults from `SWINGFORGE_DATA_DIR` (else `"data"`).

Gotcha (environment, not this WU's code): the locked `starlette==1.6.0` emits a one-time `UserWarning` nudging FastAPI's `TestClient` towards an unpinned `httpx2` package; `tests/unit/test_web.py` suppresses it locally at the one import site (`warnings.catch_warnings()`) rather than touching `pyproject.toml`'s `filterwarnings`.
